## ⚡ Быстрая установка (Промпт в один клик)

Скопируйте и отправьте этот промпт вашему AI-ассистенту (Antigravity / Claude / Cursor) в целевом проекте:

```markdown
Пожалуйста, используйте навык `cf-stats-tgbot` для интеграции бессерверной телеметрии и Telegram-консоли отчетов в этот проект:

1. Прочитайте глобальную конфигурацию из `D:\TECH\_Projects\_Skills\cf-stats-tgbot\config.json`.
2. Определите домен проекта, сформируйте имя таблицы (`stats_<site_slug>`) и выполните создание таблицы в удаленной Cloudflare D1.
3. Скопируйте `functions/_shared/telemetry/`, `functions/api/vitals.ts` и `src/utils/telemetry.ts` из каталога шаблонов.
4. Обновите `wrangler.toml`, добавив привязку базы данных D1 и необходимые переменные окружения.
5. Найдите ключевые действия конверсии (парсинг/расчет -> скачивание/экспорт) и внедрите трекинг `trackParse` и `trackDownload`.
6. Проверьте сборку командой `npm run build`, убедившись в отсутствии ошибок компиляции.
```

## 🏗️ Архитектура и принципы

1. **Единая база данных D1**: Все сайты используют одну базу D1 (`stats`), чтобы не превышать бесплатный лимит Cloudflare (до 10 баз данных).
2. **Физическая изоляция на уровне таблиц**: Каждый сайт пишет строго в свою таблицу (`stats_<site_slug>`). Нет блокировок записи между сайтами, независимые индексы.
3. **Централизованная Webhook-консоль**: Главный сайт размещает роутер Telegram Webhook. Новые сайты автоматически появляются в сводке `/today` без изменения кода главного сайта.
4. **Невидимый сбор (Stealth Ingest)**: Клиент отправляет события на `/api/vitals` через `navigator.sendBeacon`. Сервер мгновенно возвращает `204 No Content`. Реальные IP-адреса извлекаются на сервере из `CF-Connecting-IP`.

## 🛡️ Защита от перерасхода и безопасность (Zero-Overcharge Defense)

1. **Полный отказ от автоматических Cron-задач**:
   - Никаких периодических внешних curl-запросов и таймеров.
   - Исключает неконтролируемые циклы повторов при сетевых сбоях, которые могут исчерпать квоты Workers и привести к огромным счетам.
2. **100% пассивный режим по запросу**:
   - Workers и D1 потребляют ресурсы **только** тогда, когда авторизованный администратор отправляет команду в Telegram.
3. **Неблокирующий быстрый ответ (`context.waitUntil`)**:
   - Webhook отвечает Telegram статусом `200 OK` быстрее чем за 50 мс, выполняя агрегацию данных асинхронно в фоне.
   - Предотвращает шторм повторных попыток из-за 5-секундного таймаута Telegram.
4. **Двойной барьер аутентификации**:
   - Проверка заголовка `X-Telegram-Bot-Api-Secret-Token`.
   - Строгая проверка числового `admin_chat_id` администратора. Сообщения от посторонних тихо игнорируются.
5. **Debounce в памяти**:
   - 5-секундное охлаждение на команду защищает от случайного двойного клика и экономит квоты чтения D1.

## 📱 Команды Telegram

| Команда | Охват | Содержание отчета |
| :--- | :--- | :--- |
| **`/today`** или **`/all`** | 🌐 Вся матрица сайтов | Общая сводка конверсий за 7 дней по всем зарегистрированным сайтам в D1 с детализацией по каждому сайту. |
| **`/<site_slug>`** (напр. `/pinteresthd`) | 📌 Аудит одного сайта | Сопоставление трех периодов: Сегодня (24ч) / 7 дней / 30 дней + популярные форматы + Top-15 IP скачиваний. |
| **`/help`** или **`/menu`** | 📖 Справка | Интерактивное меню с динамическим обнаружением активных сайтов в D1. |
